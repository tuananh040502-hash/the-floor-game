Sao lưu & khôi phục
Google Drive
Hướng dẫn tạo Web App
  1. Mở script.google.com → Dự án mới → dán mã bên dưới vào Code.gs.
  2. Tạo một thư mục trên Drive, copy Folder ID trên thanh địa chỉ.
  3. Triển khai → Ứng dụng web: Thực thi bằng Tôi, Quyền truy cập Bất kỳ ai.
  4. Cấp quyền Drive, copy URL /exec dán vào ô trên.
  5. Sửa mã script thì phải triển khai lại phiên bản mới.
